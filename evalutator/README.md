# Оценка ТЗ через ChatGPT

Откройте `evaluate_tz.ipynb`, установите зависимости первой ячейкой и выполните ячейки по порядку.
Пути определяются относительно корня репозитория: исходное меню и ТЗ находятся в `evaluator/`
(добавлены коммитом `731b3ef`), код оценки — в запрошенной папке `evalutator/`.

Создайте `.env` в корне репозитория или в `evalutator/`:

```dotenv
OPENAI_API_KEY=ваш-ключ
OPENAI_EVALUATOR_MODEL=gpt-4.1-mini
```

В настройках ноутбука укажите `TZ_PATH` внутри `TZ_DIR`. Поддерживаются DOCX, текстовые PDF, TXT, MD.
Модель должна поддерживать Structured Outputs. Установленные зависимости проекта используются повторно.
Из корня репозитория зависимости устанавливаются командой `pip install -r evalutator/requirements.txt`.

Каждый пункт оценивается строго по четырём критериям CSV. Нехватка данных означает «не определено».
Все объяснения, выводы и дополнения меню формируются на русском. Результаты сохраняются в `results/`;
статистика вычисляется программно. Заключение и рекомендации сохраняются отдельными файлами.
Ключ и результаты не коммитятся. Реальные запросы расходуют средства OpenAI API.

Проверки без API: `python -m unittest discover -s evalutator -p 'test_*.py'`.
