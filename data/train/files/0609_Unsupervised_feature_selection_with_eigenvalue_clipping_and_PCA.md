# Unsupervised feature selection with eigenvalue clipping and PCA

Источник: https://medium.com/mercadolibre-tech/unsupervised-feature-selection-with-eigenvalue-clipping-and-pca-7ce2936aed3a

Features are like rules, you need some to have a functional model for society but too many can hurt. So, when I first saw the +4000 features we were using in our fraud models, my first thought was we could make a good improvement of the prediction power by simply “reducing the overfitting error induced by a large number of features”. Furthermore, smaller models are simpler to debug and maintain; faster to respond to, and cheaper in terms of infrastructure costs.
But choosing which feature to eliminate is not an easy task. We can’t simply project our data in a subspace because we want to keep the original explainability of the raw features. And we want as much diversity of information as we can collect because every feature has been built in response to deficiencies of past models. For this reason, many machine learning teams prefer to add every single feature and let the model learn from it. However, this is not the optimal way to go because of the bias-variance tradeoff. So we must take courage and try to tackle this problem from the very beginning of the model development.
In Mercado Libre, the size of the datasets is not negligible and the relation of the features with the target variable can be non-stationary. So, taking a big sample of data in order to try to average out this non-stationarity can lead to unbearable computational time using conventional methods. However, the relation between features is almost stationary. Thus, we could discard redundant information by comparison between features.
But how? We have to take into consideration the signal contained in each feature and discard the noise that can lead to spurious results. A method that takes into consideration the two components in a natural way, that has proven to be effective to solve our problems, is the eigenvalue clipping with PCA.
What is PCA and how does it work?
Principal Component Analysis (PCA) is like cooking; it looks easy but paying attention to every detail is the difference between a regular meal and a Michelin star result.

Then, what’s the deal? This is how people have done it for decades. Well… not so fast! In a real dataset, the vast majority of those eigenvectors are generated by noise and we need a way to discriminate between true and false correlations. One way to do it is eigenvalue clipping.
Eigenvalue Clipping
Let’s imagine you can get an idea of the distribution of noise-generated eigenvalues: in this case, we can keep the eigenvalues that fall outside this distribution as the signal and discard the eigenvalues that are falling inside as noise. Can we estimate this distribution? In the simple case of normally generated noise, we can use the Marchenko-Pastur theorem in order to get the noise-generated distribution of the eigenvectors. However, the vast majority of the noise generated in a real dataset is not normally distributed. So we need a more general way of estimating the noise distribution.

Picture two features x,y and the co-occurrence distribution is P(x,y). If x,y were independent, then P(x,y)=P(x)P(y) and the correlation between x,y must be 0. So we can force the co-occurrence distribution of the features be P(x,y)=P(x) P(y) and estimate the eigenvalues generated by the uncorrelated features.
How would you do this?
What we do is break our dataset. We take every single feature and shuffle it so that every possible correlation with other features is broken. Then, we find all the eigenvalues of this broken dataset and plot them against the eigenvalues of the original dataset. What we get is represented in the following image, where the purple bars represent the histogram of the original datasets eigenvalues, while the red line represents the histogram of the noise-generated eigenvalues.
Keeping the eigenvalues falling outside the overlapping zone ensures we’ll get a good representation of the signal contained in the features. It is worth pointing out that if the noise is normally distributed, this method gives the same exact result as the Marchenko-Pastur theorem.
So we get a subset s of eigenvalues representing signal of the original n+s eigenvalues representing noise and signal. Since we want to keep the explainability of the original features, we cannot simply project our dataset in the subset of eigenvectors with a signal.
So, what do we do next?
Well, let’s take all the signal eigenvectors v and build the filter operator
F = |v⟩⟨v|
(the operator F acts as applying sequentially the methods .transform() and .inverse_transform() of sklearn PCA to a dataset using only the signal generated eigenvalues). This operator projects our dataset D in the subspace of the eigenvector with signals v and projects it back in the original space. Equipped with our operator F we can filter our dataset D from noise F(D)=F D=|v⟩⟨v|D and get a cleaner version of the signals represented by our dataset. So our original dataset can be thought of as the sum of two components D=F D+N D where N D represents the data made out of pure noise generated eigenvalues.
And here comes the tricky part.
We can compute the new correlation matrix S of our filtered dataset F D and build the distance correlation matrix d= 1 — |S| so that when the correlation between two features is 1 or -1 the distance correlation d is 0. With this definition of distance, we can build a hierarchical clustering of our features based on the distance correlation matrix of the filtered dataset.
How many clusters do we have in the correlation space? The same quantity of the eigenvectors s with a signal!
We finally get a clusterization of the features like the image above, and we know now that every feature within the same cluster brings the same information as all the clusters, or in other words, we can now discard redundant features.
A note about this technique versus the elbow method: in the elbow method, we keep the eigenvalues that bring the most of the variance of the dataset up to an optimal point of diminishing return, where adding more eigenvalues is no longer worth the additional cost. There is no mention of the relation between noise and signal because all the eigenvectors are supposed to bring information. We cannot confirm this hypothesis anymore in our tabular data, nor in any other real dataset, so the optimal point of the elbow method may or may not be part of the signal of our dataset.
